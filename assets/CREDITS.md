# Atlanta visual assets

The visual source assets below are CC0 1.0 Universal. Audio recordings have their own CC BY 3.0 license, listed separately. Modified game assets and animation integration were prepared for this project.

- **MakeHuman base mesh and joint helpers**, MakeHuman Community. Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj . License: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md (section C). Converted to `human.json`; helper geometry removed except eyes, game skeleton and skin weights added. Opaque beachwear materials, hair, eyes, complexion and animation added in `avatar.js`.
- **Aerial Beach 01**, Rob Tuytel / Poly Haven: https://polyhaven.com/a/aerial_beach_01 . Diffuse and OpenGL normal maps, 1024 px. Saved as `sand.jpg` and `sand-normal.jpg`.
- **Spiaggia di Mondello**, Andreas Mischok / Poly Haven: https://polyhaven.com/a/spiaggia_di_mondello . Official tonemapped equirectangular panorama resized to 4096 x 2048, saved as `coast.jpg`. Used as photographic background and reflected ambient lighting.
- Poly Haven license: https://polyhaven.com/license . Download provenance and hashes retained in `asset-manifest.json`.

## Detailed skin maps

MakeHuman Community core assets, released as CC0 in September 2020 by Data Collection AB, Joel Palmius and Jonas Hauquier.
Source pack: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
License: https://static.makehumancommunity.org/about/license.html

- `skin-male.jpg`: `skins/young_caucasian_male/young_lightskinned_male_diffuse.png`
- `skin-female.jpg`: `skins/young_caucasian_female2/young_lightskinned_female_diffuse2.png`
- `skin-dark.jpg`: `skins/young_african_male/young_darkskinned_male_diffuse.png`

Each 2048×2048 map was re-encoded from PNG to JPEG, without changing the UV layout. Core MakeHuman base-mesh UVs are preserved in `human.json`. Opaque swimwear covers the character's torso/pelvis regions as appropriate; core anatomical helper geometry is excluded.
