# אטלנטה · Beach Club

משחק הקפצות כדור בחוף, בגוף ראשון. ארבעה שחקנים במעגל, כדור אחד —
מסירה בנגיעה, הרמה בחזה ותרגילי רגליים. נבנה כ-Web App סטטי עם Three.js.

## הרצה מקומית

מודולי ES דורשים שרת HTTP — פתיחה ישירה של `index.html` דרך `file://` לא תעבוד.

```bash
python3 -m http.server 8080
```

ואז לפתוח http://localhost:8080

## מבנה

| קובץ | תפקיד |
|---|---|
| `main.js` | נקודת כניסה — מצבי משחק, UI, קלט |
| `physics.js` | פיזיקת הכדור והתנגשויות |
| `scene.js` | סצנת Three.js, תאורה, שטח |
| `avatar.js` | טעינת דמויות והנפשה |
| `motion.js` · `contact.js` | תנועה ומגע בכדור |
| `opponents.js` | התנהגות שחקני AI |
| `controls.js` · `joystick.js` | מיפוי מקלדת, מגע וג'ויסטיק |
| `audio.js` | מוזיקה ואפקטים |
| `data.js` | תרגילים, שלבים, טקסטים |
| `guide.js` | מדריך ושלבי הלימוד |
| `vendor/` | Three.js |
| `assets/` | טקסטורות, מודל דמות, מוזיקה |

## תאימות

עברית ו-RTL. מותאם למובייל (PWA — ניתן להתקנה), עם מסך נעילה לאוריינטציה
לאורך במהלך משחק.
